# Security Policy

## Supported versions

The current development branch is the only supported version. This repository does not currently publish or operate a production version of the platform.

## Reporting a vulnerability

Do not report vulnerabilities through public Issues, Discussions, Pull Requests, or other public channels.

Use [GitHub Private Vulnerability Reporting](https://github.com/devrodri-com/zentra-platform/security/advisories/new).

Include a concise description, affected area, reproduction conditions, potential impact, and any suggested mitigation. Do not include data obtained from systems or people outside this repository.

We aim to acknowledge an initial report within five business days. This is a best-effort target, not a service-level agreement.

## Scope and safety

This policy covers code and configuration contained in this repository. It does not authorize testing against production or any external system.

Do not:

- access, modify, retain, or disclose data;
- test production services, domains, accounts, or infrastructure;
- disrupt availability or degrade service;
- perform social engineering, phishing, or physical-security testing;
- use destructive techniques or exceed the minimum access needed to demonstrate an issue.

No bug bounty, compensation, or safe-harbor commitment is implied unless separately confirmed in writing.
