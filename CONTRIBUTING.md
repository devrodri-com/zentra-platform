# Contributing

This repository is publicly viewable for portfolio and technical transparency purposes. It is not open source, and public visibility is not an invitation to reuse the code or contribute changes.

External contributions are not accepted by default. Do not open feature Pull Requests, implementation proposals, or dependency changes without prior coordination with the repository maintainer. Uncoordinated Pull Requests may be closed without review.

Do not disclose security vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md) and use GitHub Private Vulnerability Reporting.

Public Issues are not a customer-support channel and may be disabled. This repository does not provide product, account, order, subscription, or operational support.

Any exceptional contribution arrangement must be confirmed before work begins and does not alter the rights notice in [NOTICE.md](NOTICE.md).
